# Agent Knowledge Base — moved

The canonical voice agent knowledge base is **`agent-knowledge-base.txt`**.

This file used to hold a second, markdown-formatted copy. The two drifted apart —
the `.txt` had case studies the `.md` was missing, the `.md` had paragraphs the `.txt`
had lost — which meant whichever one got pasted into Vapi was wrong in some way.

All unique content from this file was merged into `agent-knowledge-base.txt`
(Jul 2026). Edit that one. Do not recreate a second copy here.

**To deploy a change:** edit `agent-knowledge-base.txt`, then upload it as the
knowledge base file in the Vapi dashboard. The system prompt lives in Vapi, not in
this repo — updating the file alone does not update the live agent.
